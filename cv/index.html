cldd →Python · PyPI
Evaluation harness — calibration under selective feedback

Measures model quality where the labels you need are the ones you can't observe: plant ground truth, hide it behind an approval policy, escalate severity until calibration correction fails. The deliverable is an operating frontier — 25 seeds, a distribution, not a point. A 13-claim gate recomputes every published number from hash-pinned CSVs and blocks publication when a pre-registered hypothesis fails — four did, and the claim was withdrawn. Written up in Towards AI.

intent plane →Go · Rust · TypeScript · Python
Fail-closed authorization gate for agent tool calls

The model never holds authority to act: an agent declares intent; a deterministic Go gate authorizes it against a human-signed, content-addressed policy (BLAKE3/ed25519, compiled in Rust) or refuses — unevaluable, duplicate, unsigned all deny. Every decision lands as one durable record carrying its trajectory hash, recomputable by a stdlib-only verifier that runs none of the gate's code. LangChain and MCP adapters ship with it; an NLI gate retracts unentailed rationale.
